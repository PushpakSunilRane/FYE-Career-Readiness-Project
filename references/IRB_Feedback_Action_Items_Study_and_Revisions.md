## 2. Study design described in the draft text

### 2.1 Overall purpose
Examine outcomes associated with serving as a Peer Academic Leader (PAL) in First-Year Experience (FYE) at California State University, Chico.

### 2.2 Methods (mixed methods)
| Component | What the draft says |
|---|---|
| **Survey platform** | Qualtrics (online) |
| **Consent** | Informed consent shown before survey; must consent to proceed |
| **Survey content** | Closed-ended (Likert) + open-ended items |
| **Constructs assessed** | Academic development/success, sense of belonging, leadership, communication, career readiness, transferable skills; also demographics/background (e.g., time in PAL role; current vs former) |
| **Duration** | ~15–20 minutes in one place; another draft intro says ~20–30 minutes (**inconsistency**) |
| **Follow-up** | Optional follow-up surveys over time; optional interviews |
| **Interviews** | Semi-structured with subset of current/former PALs (alumni); Zoom at Chico State; recorded (audio/Zoom note-taking); explore long-term skill application |
| **Institutional data** | If consented, may access GPA, academic standing, enrollment (FERPA-protected) |
| **Risk level stated** | Minimal risk (minor psychological discomfort; unlikely loss of confidentiality) |

### 2.3 Confidentiality / coercion protections (already drafted)
- Participation confidential, **but not anonymous**
- Identifiers collected for follow-up / linking; stored separately; unique codes; master list only for PI
- Aggregate / de-identified reporting
- Supervisor will **not** access individual responses
- Identifiable data not used for employment decisions
- Supervisor will not know who participated unless participant discloses
- Direct supervisors will not track/monitor participation
- Recruitment via standardized email; participants contact research team (not through supervisors)
- Voluntary; no impact on employment, academic standing, or FYE relationship
- Can skip questions / exit anytime without penalty

### 2.4 Draft consent / survey intro text (pages 2–3)
A draft participant-facing message (“Hello FYE Student Employees…”) is included. It covers:
- Purpose (what FYE student employees learn)
- Time estimate
- Voluntary participation
- Confidentiality / stop anytime / omit answers
- Storage (password-protected computer in FYE office + Institutional Research protected server)
- Must be 18+
- Optional follow-up interview ask
- Contact: fye@csuchico.edu / (530) 898-3705

It also mentions the survey is “based on one created by the **UVU Mentor Program**” and calls it an “**important university study**” — both phrases were flagged by IRB.

## 4. Depth analysis: what is already strong vs what is incomplete

### Already relatively strong in draft narrative
- Clear Qualtrics survey workflow  
- Confidentiality vs anonymity distinction started  
- Separation of identifiers from responses  
- Strong anti-coercion / no employment impact language

### Critical gaps (why IRB is blocking / requesting revisions)

| Gap area | What’s wrong / missing | Impact |
|---|---|---|
| **Recruitment email attachment** | Required elements incomplete / not uploaded as full draft | Cannot verify recruitment ethics |
| **Consent form completeness** | Missing title, IRB #, PI, IRB contacts, risks/benefits, eligibility, demographics disclosure, print/save, consent click | Consent not compliant |
| **Wording problems** | “Important university study”; unexplained “UVU” | Undue influence / unclear sponsorship |
| **Anonymity clarity** | Reviewer still asks if anonymous vs named/linked | Dual-role protection must be airtight |
| **Survey skip logic** | Consent contradicts itself on required vs skippable items | Participant rights unclear |
| **Interview protocol** | Not attached | Qualitative arm not reviewable |
| **Interview consent** | Referenced but not uploaded | Second consent pathway incomplete |
| **FERPA academic data** | Mentioned in methods; consent must explicitly list data types | Legal/privacy compliance |
